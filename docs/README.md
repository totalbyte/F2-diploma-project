## Нефункціональні вимоги (NFRs Matrix)

Зведення нефункціональних вимог до системи. Повні формулювання та критерії приймання — у [1_analysis.md](1_analysis.md), розділ «Постановка задачі та формування вимог».

| Категорія | ID | Вимога | Цільове значення |
| --- | --- | --- | --- |
| Продуктивність | NFR-P1 | Затримка REST API читання | p95 ≤ 200 мс, p99 ≤ 500 мс при 300 RPS |
| Продуктивність | NFR-P2 | Створення бронювання | p95 ≤ 500 мс при 50 RPS; 100 паралельних запитів на одне місце — рівно 1 успішний |
| Продуктивність | NFR-P3 | Телеметрія та доставка змін | ≥ 1 000 повідомлень/с; брокер → клієнт через SignalR ≤ 2 с (p95) |
| Продуктивність | NFR-P4 | Кешування та асинхронна обробка | Частка влучань у кеш ≥ 90 %; затримка обробки споживачем ≤ 5 с (p95) |
| Продуктивність | NFR-P5 | Клієнтська продуктивність (p75) | LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1 |
| Безпека | NFR-S1 | Стандарти та ланцюг постачання | OWASP ASVS 5.0.0 L2; 0 вразливостей Critical/High; SBOM CycloneDX |
| Безпека | NFR-S2 | Автентифікація та авторизація | OAuth 2.0 / OIDC + PKCE; JWT (ES256) ≤ 15 хв; 100 / 600 запитів/хв, далі HTTP 429 |
| Безпека | NFR-S3 | Паролі та сесії | Пароль ≥ 15 символів (єдиний фактор); Argon2id (m = 19 MiB, t = 2, p = 1); WebAuthn для операторів і адміністраторів |
| Безпека | NFR-S4 | Шифрування | TLS 1.3; MQTT через TLS (порт 8883); AES-256 для даних у стані спокою |
| Безпека | NFR-S5 | Персональні та платіжні дані | GDPR (ст. 17, 25); координати спостережень ≤ 30 діб; дані карток не обробляються (переадресація на LiqPay) |
| Безпека | NFR-S6 | Доступність | WCAG 2.2 AA (ETSI EN 301 549 V4.1.1); axe-core: 0 порушень critical |
| Надійність | NFR-R1 | Доступність сервісів (SLO) | Booking і Payment — 99,9 %; інші сервіси — 99,5 % |
| Надійність | NFR-R2 | Розгортання та автомасштабування | Azure Container Apps + KEDA; minReplicas 1–2, maxReplicas 10 |
| Надійність | NFR-R3 | Відмовостійкість | До 3 повторних спроб; Circuit Breaker при ≥ 50 % помилок у вікні з 20 викликів; DLQ після 5 спроб |
| Надійність | NFR-R4 | Резервне копіювання та відновлення | RPO ≤ 5 хв, RTO ≤ 60 хв (PITR) |
