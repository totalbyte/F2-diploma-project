# ParkOver

Хмароорієнтована подієво-керована платформа управління міським паркуванням з моніторингом зайнятості в реальному часі, бронюванням та програмою лояльності.

*Cloud-Native Event-Driven Smart Parking Platform with Real-Time Space Availability, Reservations and Loyalty Program.*

Кваліфікаційний проєкт бакалавра, спеціальність F2 Інженерія програмного забезпечення.
